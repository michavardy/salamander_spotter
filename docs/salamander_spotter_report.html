Technical report

Salamander Spotter

Re-identifying individual fire salamanders from the pattern of yellow spots on their backs — the problem, the data engineering, the methods, the checks, and what the results actually deliver.

Prepared 2026-08-29 Dataset all_sasa_norm_2026_23_07 Code pipeline/spot_transformer/ Status research / not yet field-deployed

In one line. Given a new photo of a fire salamander, decide whether it is an animal already in the database (and which one) or a never-seen individual — using only the natural spot pattern, no physical tags.

The work has produced a complete, honestly-measured pipeline: machine-extracted spots → a fixed 62-number description of each spot → a small trained rule that scores a photo against each known animal → a ranked shortlist with a calibrated confidence and an “abstain” option. On a modest gallery of about 65 candidate animals it ranks the correct known individual first 60% ± 10% of the time (five-fold cross-validation), up from 43% for an untrained baseline and 35% for a whole-image approach. The harder half of the task — correctly flagging genuinely new animals — is weaker: novelty is separated at an area-under-curve of roughly 0.60–0.69 and the precision-first operating point commits to only 6–18% of photos. Repeated diagnostic checks locate the ceiling in the spot description and the label quality, not in the matching model, and show that adding more photos of the same kind will not move it.

1The problem

Fire salamanders (Salamandra salamandra) carry a unique, lifelong pattern of yellow spots on a black body. That pattern is effectively a natural fingerprint, so individual animals can be tracked over time without ever catching or tagging them: photograph the animal, and the pattern says who it is. The field collection this project serves began as 445 photos from Kibbutz Sasa, Israel, and has since grown by merging further field collections. Its value is unlocked only if, for each photo, the question “have we seen this one before?” can be answered reliably — the foundation for non-invasive population counts and mark-and-recapture studies.

It is open-set re-identification, not classification

The list of individuals is not fixed. New salamanders keep appearing, so the system cannot be a classifier with a fixed set of classes. Every incoming photo needs two decisions:

  1. Match — is this the same individual as one already enrolled, and if so which one? (a one-against-many search, then a yes/no check on the best candidate)
  2. Enroll as new — if no enrolled animal is a confident enough match, register this photo as a new individual.

Concretely, the system turns a query photo into a ranked list of candidates, each with a similarity score between 0 and 1, and applies a decision threshold: above it, “same as candidate X”; below it, “new animal.” A third answer, abstain (“too blurred / too few spots / cannot tell”), is required as well, each with a calibrated confidence.

Why it is hard

  • Only the spot pattern is stable. Pose, body curvature, camera angle, lighting, skin wetness and background all vary widely between photos of the same animal. The system must be blind to everything except the spots.
  • Very few photos per animal. At project start, 203 of 290 individuals appeared in a single photo. Even after growth the collection averages roughly 1.4–2 real photos per individual. There is nowhere near enough data to train a per-animal model; the system has to learn a general sense of “same pattern vs different pattern” that transfers to animals it never saw in training.
  • The labels are machine-made. The per-spot annotations come from an automatic pipeline (described in section 2), not from hand-verification, so the training signal contains errors.
  • The costs are lopsided. A false match merges two animals into one and permanently deflates the population count — mark-and-recapture cannot undo it. A missed match only inflates the count with a phantom “new” animal, which later photos can correct. So the system is scored with precision weighted twice as heavily as recall (the measure called F0.5).

2Data engineering

Everything downstream depends on turning raw field photos into a clean, pose-normalised description of each animal’s spot pattern. That is done by an automatic labelling pipeline, then packaged into a versioned dataset with a DuckDB database of per-photo and per-spot rows.

How identity is labelled

Identity is encoded in the filename. A file stem is <code>_<individual>_<instance> (e.g. aj_1_2); the identity label is the stem with the trailing instance number removed (aj_1). Two photos with the same label are the same animal; different labels are different animals. This convention is both the training signal and the evaluation ground truth. Note that aj_1 and aj_2 are different animals.

The automatic labelling pipeline

All four stages are automatic and approximate; none is hand-verified.

  1. Spots — the “magenta trick.” Instead of asking a vision model for spot coordinates (which it does poorly), the model is asked to recolour every yellow spot flat magenta. OpenCV then keys that one colour and traces each spot’s outline, centroid, area and pixel mask deterministically. Annotation becomes a recolouring task, which the model is genuinely good at.
  2. Body outline and centre-line. The model paints the whole trunk-and-tail one colour (legs excluded); the mask is keyed, and the head/tail tips and centre-line are then computed from the mask’s shape. The centre-line is defined as the curve with equal body area on each side, so it bisects the animal by construction. Asking the model directly for a bisecting line failed the “does it actually bisect?” check for every model tried — the line always hugged one flank — whereas tracing the two visible edges and averaging them works, and on a synthetic curved body tracks the true centre to within 2 pixels.
  3. Body grid. The centre-line is cut at 25/50/75% of its length into four segments (segment 1 = head end) and split left/right, giving every spot a position key that survives the animal being photographed at any angle or scale. Coverage: 1,867 of 1,869 photos got a usable axis; 1,857 passed all geometric quality gates, 10 failed and are flagged.
  4. Quality markers. Cheap, model-free per-photo scores from 0 to 1 (sharpness, lighting, spot-extraction quality, body-extraction quality, and an overall score) plus raw measurements, used later to filter or down-weight bad photos.

Synthetic training views

602 of the 1,869 images are model-generated re-renderings of an animal already in the set — different lighting, background and angle, spot pattern held fixed — named <label>_g<k> so they inherit the same identity label. They add 855 same-individual pairs and take 352 individuals out of single-photo status. They are used for training only: they never enter the gallery or the query set, because evaluating on generated images would measure the image generator, not the matcher. A self-consistency filter keeps a synthetic view only if its extracted spot set still matches the source animal.

The per-spot description the matcher consumes

Each spot is turned into a fixed list of 62 numbers, built by hand (no training), in two blocks:

  • Shape — 37 numbers. A normalised Elliptic Fourier Descriptor of the spot outline, keeping the first 10 harmonics. This is unchanged by translation, scale, rotation and where the tracing starts, and the dropped high harmonics remove pixel-edge jaggedness. Two deliberate consequences: absolute size is not represented (a big blotch and a small dot with the same outline get the same 37 numbers), and fine lobes and notches are partly filtered out along with the noise.
  • Position — 25 numbers. Body-intrinsic location: how far along the head–tail line the spot sits, how far off the centre-line (as a fraction of body width), and which side. Encoded as smooth sine/cosine features so that spots far apart on the body land far apart in the description, and so the encoding survives the photo being rotated or resized.

Each block is scaled to unit length and the two are joined, so the similarity between two spots is the average of their shape agreement and their position agreement — an additive rule in which neither block can veto the other. The similarity numbers are low in absolute terms (about 0.3–0.5 even for the same animal); only the ranking of matches matters. Conjunctive variants (shape and position must agree) and a variant that re-adds size and shape-irregularity were built and tested (section 4).

The evaluation harness

Because the data is small, the way results are measured is itself engineered carefully.

  • Split by individual, five-fold cross-validation: no animal appears in both training and test. Test queries are drawn only from individuals with two or more real photos. Synthetic images are training-only.
  • Two fixed anchors on every run. A dummy matcher with random descriptions must score at chance; an oracle that reads the labels must score ~1.0. If the dummy ever scores well, something is leaking and no other number is trusted. The acceptance check (emb-selfcheck) asserts 9 of 9.
  • Confidence intervals over individuals, not queries, because several queries from one animal are correlated; query-level intervals come out 2–3× too narrow.
  • Gallery size always stated. The same matcher scores rank-1 of 0.60 against ~65 candidate animals and a fraction of that against ~687; chance itself moves from 0.071 to 0.010.
  • Metrics. Identification: rank-1 / rank-5 (is the right animal the top guess / in the top five). Verification: area-under-ROC for telling same-animal from different-animal photo pairs. Open-set: area-under-ROC for telling new animals from known ones. Population census: F0.5 of the match-or-new decision, plus how far the resulting head-count is off.

Human supervision

Two small web tools collect human judgement: a per-spot “interesting spot” tagger (~8,700 per-spot labels over 362 photos, about a quarter tagged interesting; a later revision has ~2,970 over 477 photos) and a pair-review tool where a reviewer accepts or rejects proposed spot-to-spot correspondences and writes why. The reviewer’s reasons reduce to six: penalise an unmatched characteristic spot, a round/plain spot, few matches, mismatches, a position difference, a shape difference.

3Methods — the short version

Three things could be learned from data: the description of each spot, the rule that combines spot matches into an animal-level score, or both together. The recurring finding across the whole project is:

Learn the combining rule, not the description.

Identity labels are far too scarce to train a spot or image encoder (~1.4 photos per animal). But every (query photo, candidate animal) pair is a labelled example for the combining rule — about 6,000 per fold — so a tiny model over general, animal-agnostic match statistics has abundant supervision and transfers to unseen animals. Every time a more expressive model was tried, cross-validation variance beat it. The simplest model with the most direct supervision won, repeatedly.

The pipeline end to end

  1. Extract spots from the photo (magenta trick).
  2. Describe each spot as the fixed 62-number vector.
  3. Score the query photo against each enrolled individual using 17 match statistics: how many query spots have a good partner, how broad that agreement is, how many partnerships are mutual (each spot is the other’s best match), how geometrically consistent the matched spots are, and size-normalisation terms.
  4. Combine those 17 numbers with a logistic regression (a weighted sum through an S-curve) into one score per candidate.
  5. Decide. Rank the candidates; convert the top score to a calibrated probability; above the threshold, report the matched individual; below it, “new animal.” Abstain when the photo has too few spots or low quality.

4Methods in depth

4.1  Why spots beat the whole image

A learned whole-image embedding never rises above the level of simply averaging the spot vectors (rank-1 ~0.35–0.37 either way). Training pulls an untrained model up to the average and no further. The reason is data: with ~1.4 photos per animal there are too few same-animal pairs to teach an encoder the invariances it would need.

Spot voting needs no training and does much better. For each spot in the query photo, find its single best-matching spot on a candidate animal and add up those best scores; the candidate with the highest sum wins. This scores rank-1 0.556 on the easy fold and 0.434 ± 0.092 over five folds, against 0.352 for the whole image. The counter-intuitive part: the average same-animal spot pair is not similar (a spot classifier separates same-animal from different-animal spot pairs at area-under-curve ~0.51, essentially chance). Voting works anyway because it keys off the nearest match, and the handful of truly corresponding spots do match strongly (precision 0.77–1.0 once similarity is above 0.75). So the signal lives in the best few correspondences, not in the average.

4.2  Why training the spot description fails

Training a spot encoder with a same/different loss on identity labels — tried both with cross-spot context (a transformer) and without (a plain network) — makes the spot classifier much better (area-under-curve 0.51→0.72) but makes voting worse (rank-1 drops to ~0.30–0.33). Both architectures fail the same way, which points at the objective rather than the model: a “same individual” loss pulls together an animal’s genuinely different spots, which destroys the one-to-one correspondence that voting relies on. The hand-built 62-number description already preserves that correspondence. Conclusion recorded in the project: do not learn the spot description for this task.

4.3  The learned combining rule (the deliverable)

Keep the 62-number spot descriptions fixed. Treat every (query photo → candidate individual) match as one labelled example and learn the function that turns its 17 match statistics into a score. The statistics are all animal-agnostic (they describe a match, not an identity), so the rule generalises to animals not seen in training.

Confidence. The gap between the top and second candidate scores predicts whether the top guess is right: low / medium / high gap corresponds to accuracy 0.33 / 0.68 / 0.80 — usable as-is. Platt scaling then fixes the probability numbers (the most-confident bin was claiming 0.72 when it was right 0.22 of the time; after scaling it claims 0.18).

4.4  The distinctiveness / “strict” track

Driven by the human reviewer’s written reasons, a second matcher scores a pair as coverage × support: coverage is the fraction of an animal’s distinctive spot “mass” that is explained by good matches (an unmatched characteristic spot drags it down), and support rises with the number of corroborating matches (few matches → low). Each spot’s distinctiveness weight is learned from the ~8,700 human tags by a six-factor logistic regression that recovers the human’s “interesting” labels at area-under-curve 0.750 ± 0.018 (a hand-tuned blend gets 0.708). What the fit says is “special”: shape irregularity (+0.96) and size (+0.68); being isolated or rare fits at essentially zero. The reviewer’s “spot 96 / spot 100” language turned out to mean size percentiles, not spot identifiers.

On a quality-filtered subset this matcher reaches census F0.5 0.622 ± 0.045. On the full, harder gallery with no quality filter it drops to 0.347 ± 0.124 — still the best and most stable of the tried scorers, and notably: letting a logistic regression re-learn the factor combination makes it worse (0.245), because the learned combo dilutes the human thesis and leans on size-normalisation. Removing the human distinctiveness supervision entirely drops census F0.5 from 0.609 to 0.493 and novelty separation to chance — the human signal is load-bearing.

4.5  Joint training, tested and set aside

A model that learns its own spot description and the voting rule together, through a differentiable voting head, reaches census F0.5 0.609 ± 0.089 — but a version with the spot encoder frozen reaches 0.600. Learning the representation adds almost nothing; the differentiable-voting objective does the work. This is consistent with 4.2.

7Interpretation — how well it solves the problem

What works

  • Spots plus voting is the right representation. Untrained spot voting (rank-1 0.43, five folds, ~65 candidates) already beats every whole-image approach (~0.35) with no training, and the learned combining rule lifts it to 0.60 ± 0.10, positive on all five folds.
  • The output shape the problem asked for exists. Ranked candidates, a similarity in [0,1], a decision threshold, a calibrated probability, and an abstain path (commit to 6–18% of photos while keeping emitted matches ≥90% precise).
  • Human distinctiveness supervision matters. Removing it costs census F0.5 0.609 → 0.493 and drops novelty separation to chance.
  • The evaluation is trustworthy. Fixed dummy/oracle anchors, individual-level intervals, gallery-size discipline, pre-registered decision gates, and control arms that must fail. These checks caught multiple would-be results as artifacts.

What does not yet work

  • Closed-set ranking is well short of the aspirational target (rank-1 ~0.85). The honest best is 0.60 at a ~65-candidate gallery, and a fraction of that at the full ~687-candidate gallery. For context, published wildlife re-identification on clean, curated data reaches rank-1 0.6–0.9; this project works from machine-extracted, unverified spots with ~1.4–2 photos per animal.
  • The open-set decision is the hard half. Deciding “this is a new animal” separates at area-under-curve 0.60–0.69, and the precision-first operating point has recall around 0.10. Before gating, the population count over-counts by tens of animals per fold.
  • The ceiling is the spot description, and it is firm. Eight descriptions — hand-built and learned — all score 0.47–0.51 against human accept/reject verdicts on single spot matches (chance 0.50). The human reviewer is judging on configural arrangement and absolute size relations that the 62-number vector does not encode. Learning the description from identity labels fails (too few labels); self-supervised learning from mined correspondences also fails to beat the hand-built description.
  • More of the same data will not fix it. The data-scaling slope is −0.006 in census F0.5 per ~330 added images and declining, and the synthetic study shows the learned model is not limited by training scale.
  • The label substrate is noisy. Only 70% of spots get a body position; a spot re-appears across two photos of the same animal just 24% of the time; about a third of individuals are at chance-level self-consistency; 8 or more duplicate identities are confirmed.

Where the leverage is

The project’s own conclusion, backed by the checks above: the binding constraints are data quality and the spot description, not the matching model. Scoring-rule work is closed. The open levers are all data: de-duplicate identities, resolve multi-animal frames, align to the body axis, break results down per source collection, and build a small hand-verified validation set so label noise can actually be measured. A richer spot description — one that carries absolute size and configural geometry the human demonstrably uses — is the other open direction.

Bottom line

Salamander Spotter is a working, honestly-evaluated pipeline that solves the easy fraction of the problem. At roughly 90% precision it will commit to about 6–18% of query photos and, on a modest gallery, rank the correct known individual first around 60% of the time; for the rest it can answer “new / not sure.” It does not yet deliver field-ready open-set re-identification at full population scale. The gap has been diagnosed rather than guessed: it lies in how each spot is described and in the quality of the machine-made labels, and both of those are addressable.
